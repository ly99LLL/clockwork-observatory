# 午夜落星 · Clockwork Observatory

[手机直接试玩](https://ly99lll.github.io/clockwork-observatory/) · [下载二维码 PNG](dist/share/clockwork-qr.png) · [下载矢量 SVG](dist/share/clockwork-qr.svg)

本地网页街机原型，参考用户提供的钟楼机械概念图。背景使用原图作装饰，所有前景机关、小球、镜头和反馈由 Canvas 实时绘制。

启动后星球持续滚动，每层压力倒数。A / D 或左右方向键旋转金色缺口，将它对准下方绿色出口：弦月转轮、摆动漏斗、需要空格按压的闸门、螺旋轨道、会自行反转的星轮。第四层的小球沿真实绘制的 1.5 圈螺旋槽从内圈走向外圈：D 推进，A 减速，到达外缘后对准出口自动释放，没有额外的隐藏蓄能条件。其余出口对准后自动下坠，闸门需主动按压。五层顺序通过，连续释放累积连击与星尘。超时损失一颗星、打断连击，在当前层立即反冲重试；三次耗尽则结束。

P / Escape 暂停，R 立即重来；触屏使用左右旋转按钮与按压按钮，也可拖动转盘。切到后台自动暂停。最高分保存在本机浏览器，无法存储时仍能游玩。默认在点击开始后播放合成机械音，可关闭。

## 手机触屏版

手机竖屏使用底部双手控制区：按住 ↶ / ↷ 连续旋转，第三层轻触“按压闸门”。支持两个手指同时旋转与按压、指针取消与安全释放，横屏会将控制区移至右侧。提供实时进度、倒数、暂停、重新开始和第四层练习。适配动态浏览器高度及刘海、底部手势区域，游戏与按钮保持在可见区域内。

## GitHub Pages 发布

`.github/workflows/pages.yml` 在 main 分支推送后先执行玩法检查，再把 dist 作为静态游戏发布至 GitHub Pages。首次需在仓库 Pages 设置中选择 GitHub Actions。网页不需要账号、API 密钥或后端。

## 钟楼风格二维码

部署成功后，用实际 HTTPS 网址执行 `python tools/make_qr.py <网址>`，会生成 artifacts/clockwork-qr.png 和 SVG。使用深青色模块、暖象牙底、黄铜外框与齿轮装饰，保留四模块留白，并通过 OpenCV 解码核对网址。生成工具需要 qrcode、Pillow、opencv-python，不影响网页运行。

运行：`python -m http.server 4178 --bind 127.0.0.1 --directory dist`。无需安装依赖或联网；也可打开 dist/index.html。

点击“Ⅳ 练习”或打开 `http://127.0.0.1:4178/?v=4&practice=4` 可单独练习第四层，通过后立即结束，不写入最高分。点击“全塔”回到正常流程。

验证：`node checks.cjs`。涵盖持续运动、倒数与失败、暂停、五层顺序、闸门主动输入、螺旋曲线约束、推进与减速、拖动驱动、单层练习、完整连击以及八个随机种子的完整输入通关。该模型使用曲线约束运动与旋转推进，面向街机节奏，不是完整刚体仿真。
